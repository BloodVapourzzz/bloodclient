BLOOD CLIENT — READ ME FIRST
==================================

INSTALL THE LAUNCHER
--------------------
1. Optional: right-click Install-BloodClient-Certificate.bat and choose Run as administrator.
   It installs the public Blood Client certificate so Windows can show the publisher name.
   The .bat needs BloodClient-Root-CA.cer beside it. No private key is included or required.
2. Double-click BloodClientLauncher-Setup-2.0.0-signed.exe.
3. Open Blood Client, choose an account and Minecraft version, then press PLAY.

The installer is per-user. It does not modify your .minecraft folder.

JARS ONLY (WITHOUT THE LAUNCHER)
---------------------------------
1. Install Fabric Loader 0.20.1 for your Minecraft version.
2. Put the matching Blood Client jar into .minecraft\mods.
3. Launch the Fabric profile.

WINDOWS SECURITY NOTE
---------------------
Windows may show a download warning because the file came from the internet. The
certificate is self-signed, not issued by a public certificate authority. The optional
certificate helper installs only the public certificate; never share a private signing key.
