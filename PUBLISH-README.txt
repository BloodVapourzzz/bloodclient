# blood-website-publish - ready to upload

Upload the CONTENTS of this folder (index.html + downloads/) to GitHub Pages,
Cloudflare Pages or Netlify. Full step-by-step: ../BloodClient-Publishing-Guide.md

- index.html - the website (single file, no build step)
- downloads/ - launcher installer + the three alpha.5 jars the page links to
- channel.json - launcher auto-update file (edit the two placeholders first,
  then keep it in the same GitHub repo; see guide Part 4)
