What’s new

Alpha.8: new B logo, same FPS engine.

Every Alpha.8 jar carries Blood’s internal FPS performance engine: lighter HUD rendering, bounded text/cosmetic caches, faster catalog and sidebar paths, renderer compatibility checks, and measured frame diagnostics with /bloodperf. Sodium remains the recommended optional renderer — Blood never bundles it and makes no invented FPS-percentage claims. Shield Banner Studio is gone entirely; appearance sync, exclusive packs and Player Ping Display remain.

⚡
Latest alpha.8

FPS performance engine

Built into the 1.21.11, 26.2 and 26.3 jars. Blood reduces its own repeated HUD measuring, bounds fitting and cosmetic lookups, while every cache stays small and clears safely when settings, worlds or resources change. Alpha.8 also deletes the broken shield-banner editor/rendering path instead of leaving a toggle behind. In game, /bloodperf reports measured average FPS, p50/p95/p99 frame times, stutters and 1% lows. For the biggest renderer gains, add Sodium separately: 0.8.14 for 1.21.11 or 0.9.2 for 26.2/26.3.

Install

Running in a few steps.

1

Back up

Back up important worlds, screenshots and your Blood config before changing alpha jars.

2

Pick one jar

In Option 02 above, choose your Minecraft version from the dropdown and download the single matching .jar.

3

Add Fabric API

Install the exact Fabric Loader/API pair from the compatibility table. Remove any older bloodclient jar.

4

Open Blood

Launch the game and press Right Shift. Enable Player Ping Display under Interface.

First settings to try

  • Player Ping Display: Right side, colors on, ms on, 64-block range.
  • Keep the HUD Ping module for your own latency and Tab List for numeric tab pings.
  • Use “Ping on my name tag” only if you also use third-person own-tag display.

Please don’t install these as mods

  • The outer release ZIP itself.
  • The nested source ZIPs or -sources.jar files.
  • Two Blood Client runtime jars in the same mods/ folder.

FAQ

Questions, without the fog.

Where do I report a bug or get help?

Join the Blood Discord for community help and bug reports. Say which Minecraft version and download type (launcher or .jar) you used, what happened, and attach a screenshot or crash report/log if you can. Never post Microsoft passwords, sign-in/device codes, tokens, or private cosmetic codes.

Is Player Ping Display the same as the Ping HUD?

No. The Ping HUD shows your own latency in a floating HUD. Player Ping Display adds each visible player’s server-reported latency beside their in-world name tag. Tab List is a third option that puts numbers in the tab list.

Can it show players through walls or while sneaking?

No new visibility is created. Blood only appends text after vanilla has already produced a visible player name tag for that render state. If vanilla hides the tag, Blood does not draw a replacement.

Why is someone’s ping missing?

The client may not have a matching player-list entry, or the server may report a negative/unavailable latency. Blood skips those instead of inventing a number.

Do skins and cosmetics show to other players?

Yes — to other Blood Client users who opt into the same hosted HTTPS Blood presence service. Online accounts are Mojang-verified; standard offline-mode accounts on offline servers use an explicitly unverified device-signed lane. They see your equipped imported skin and cosmetics on your player model, plus the Blood tab-list badge. Vanilla/other clients still see official account appearances; Blood never changes your Mojang skin, bypasses Minecraft server login or proves official cape ownership. No public presence endpoint is preconfigured.

Does Blood change combat?

No. Blood does not change reach, damage, attack timing, hit registration or server state. Modules present client-known information or alter local presentation.

How do the exclusive Owner / Co-Owner cosmetics unlock?

Everyone can preview them. Pressing Password & Equip in the wardrobe asks for that tier’s password; a correct code equips the design for any account type. The code is checked only on your client against a salted hash and is never sent to a server — treat it as a friendly lock, not DRM. Passwords are shared privately by the Blood team; they are not printed on this page.

How do I get the best FPS?

Use an alpha.8 jar and add Sodium to your mods folder (0.8.14 for 1.21.11, 0.9.2 for 26.2 and 26.3) from Modrinth — Blood recommends it but never bundles it, and works fully without it. In game, type /bloodperf to measure your real frame times, stutters and 1% lows.

Where did Shield Banner Studio go?

It was bugged, so alpha.8 removes it entirely — no editor, stored design, presence shield field, or shield-rendering hook. Existing settings with the old key still load; the key is ignored. The separate Shield status HUD and Low Shield viewmodel option remain.

Does the launcher include alpha.8?

Yes — launcher 0.3.0-beta.4 bundles the same three alpha.8 jars and verifies the matching jar by SHA-256 before installing it into a managed Blood profile. The standalone selector above gives the identical jar for an existing instance.
